Design decisions

  • Layout, not just color. Every Hub section became an MD3 "card" (tonal surface-container-low, medium/12px shape) instead of a bare column, giving the window real visual hierarchy for the first time.
  • State layers, not new fills. Hover/press on filled and tonal buttons overlay a translucent wash of the foreground color (8%/10% opacity) rather than swapping to a different color, per MD3's state-layer system.
  • A real disabled state. The per-row "Save" button in Speakers used to silently no-op on an empty name; it's now visibly disabled (dimmed border/text at MD3's 12%/38% opacity) until there's something to save.
  • Differentiated motion per Flow Bar state rather than one generic spinner: a breathing pulse for Recording (urgency), an eased sweep for Thinking (progress), a one-shot cross-fade for Done (completion), and no motion at all for Idle/Error -- motion conveys state, it isn't decoration.
  • One added color role. success-container/on-success-container aren't part of the official MD3 role set (MD3 has no built-in "success" pair) -- they're a same-shape custom addition for the Done state, documented as such in theme::color.
